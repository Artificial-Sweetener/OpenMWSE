# Open Morrowind Special Edition

**OpenMWSE is my opinionated fork of [OpenMW](https://github.com/OpenMW/openmw).**

I love OpenMW. It also does not do all of the things I want it to do. It's time to make it do those things.

Currently, this contains mostly changes to the renderer...

- Atmospheric scattering (like in MGE XE)
- Enhanced shadows with cheap-ish distant shadows
- Fake water meshes get real planar reflections (expensive!)
- Option to use MGE XE water shaders directly, including 3D water waves
- Fixes to 3D water waves to keep them from clipping through landscape and statics inappropriately

Probably a few other things I'm forgetting!

Later, I'll merge in and include the progress I made on the MWSE => OpenMW translation layer.

I would like to work more on this but had to shift my focus elsewhere when I realized one of my projects needed a serious overhaul. When I feel more comfortable with the state of that project I will turn my attention back here!
